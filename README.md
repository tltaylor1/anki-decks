# PowerShell flashcards

An Anki deck of 133 cards covering PowerShell from the basics through
scripting: the pipeline and its objects, variables, arrays and
hashtables, functions and advanced functions, error handling, modules,
remoting over WinRM and SSH, jobs and runspaces, parallelism in
PowerShell 7, and script security.

Written from the documentation and daily use, with the cards checked
against current PowerShell 7 behavior in August 2026; where Windows
PowerShell 5.1 differs, the card says so.

## Getting the deck

Download [powershell.apkg](powershell.apkg) and import it into Anki
with File, then Import. The same cards are in
[powershell.csv](powershell.csv) as plain front and back columns, which
is the file to read if you want to see the content without Anki, and
the file git diffs when cards change.

## Updating

The deck is maintained in a live Anki collection and exported here with
[scripts/export.py](scripts/export.py). Corrections are welcome: open
an issue naming the card front and what is wrong with the back.
